# DAPseq_snMultiome

This repository contains analysis scripts and metadata associated with the manuscript:

**A sorghum TF–DNA interactome links ancient ERF clade divergence to cell type-resolved salinity responses**

The repository provides workflows for DAP-seq read processing, peak calling, motif discovery, peak annotation, ERF clade classification, evolutionary analysis, AlphaFold3-derived structural analysis, snMultiome processing, peak-to-gene linking and ERF regulatory network construction.

Raw sequencing data are deposited in public repositories as described in the manuscript. This repository does not store raw FASTQ files, BAM files, Cell Ranger output directories or other large intermediate files. Instead, scripts are provided to reproduce the main analyses from the deposited data and processed input tables.

Final figure assembly was performed manually from the analysis outputs. Scripts for key quantitative plots and source-data generation are included where applicable.
